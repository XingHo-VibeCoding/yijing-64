# 前端规则 · 易经六十四卦（已确认版 2026-09-29）

## 0. 用法

改动界面的固定顺序：**§5 修改前检查 → 动手 → §6 修改后验证 → §7 可访问性**。
每次真实调用本 Skill 后，在文末「调用记录」追加一行（日期 ｜ 做了什么 ｜ 用了哪几节）。

## 1. 页面层级

- 总表 = 宣纸底 + 木牌令牌（上圆下方）；详情 = 竹简记录风；记录/测验各自成区
- 转场层是 **App 顶层唯一实例**（`overlay` + `viewNode` 赋值模式）；⚠️ 排在最后的无条件赋值分支必须加 `if (viewNode === null)` 守卫，否则静默覆盖前面的分支
- hash 路由三处：`#/h/<卦序>` 详情、`#/quiz` 测验、`#/records` 记录；换页藏在墨下（`onCovered`）
- **fixed 定位的关键视觉层必须 portal 到 body**（`.page` 带 filter 时 fixed 基准会变成该元素，画布只盖住卡片盒）

## 2. 颜色与字体

- 只用传统风变量：`--paper / --wood / --slip / --seal`（index.css 末尾）
- **禁冷灰文字**（`#8c959f` 系已全部清零，别复活）
- 深色卡 / 墨底上的字 → 暖金 `#f2d98c`、米色 `#f5ead0`；浅宣纸上的字 → 深墨 `#171512` / `#4a3115`
- 对比度硬线：正文与小字（含 12.5px）≥ **4.5**（已实测达标对：`#6f5330`、`#6f5636` 对纸面 `#e9d9b4`；
  浅底砂金字 `#8a5713` 对宣纸 ≈5.5；压在画上的金字 `#8a5c18` + 深色描边）
- 原文块衬线字体栈，末尾补 `SimSun-ExtB`（护 CJK 扩展区生僻字）
- ⚠️ **浅底不要发光**：白底已接近亮度上限，浅色辉光只会把字往外晕（越发光越糊）——
  `#a9762c` + 三层金色光晕在白云上实测发虚且只有 3.6:1（用户报过「看不清字」）。
  浅底的正解是「**加深字色 + 极淡深色投影**」（把字从白底托起来）；发光是**深底**才有的手法，别照搬
- 压在**画/照片**上的字（如水墨山水）：字色加深 + **深色描边**（把笔画从杂乱背景里择出来）
  + 一层极淡浅色柔光（兜住墨深处），这样深浅底都读得出

## 3. 卡片与按钮

- 木牌令牌：上圆下方；卡片内阴影质感别破坏
- **交互元素绝不嵌进卡片 button**（收藏钉 = `li` 的兄弟节点，绝对定位）
- 装饰全部绝对定位 / 外圈阴影，**不改卡片内部布局与尺寸**
- 写入型按钮：250ms 防连点（disabled + opacity）；失败给可理解提示（`role="alert"`，4s 自清）
- 银环/环带用 `::after` + mask 挖环（**透明 border 造环宽，padding 无效**）

## 4. 移动端适配

- 弹性宽度一律 `min(Npx, %)`；横排控件组加 `flex-wrap` 兜底
- 新增横排控件必须验证不产生横向溢出（`scrollWidth ≤ clientWidth`）

## 5. 修改前检查

1. `git status --short` 干净才动手
2. 新类名先 grep 全库查撞名（`.q-bar` 撞过进度条）
3. 改既有选择器前，全文检索其后文覆盖（判断活/死规则，不能只查修订段）
4. 一次只改一件事；改数据/结构先问用户

## 6. 修改后验证

1. `python .workbuddy/doc-check.py` 全绿
2. `npx vite build --outDir .workbuddy/dist-check-<新名字> --emptyOutDir`（别删已存在的 dist/）
3. **R3：界面结论只认截图** —— `agent-browser set viewport 1440 900`（**每轮截图前重设**，别默认沿用）；点击用 eval 里 `b.click()` + 存在性重试；时效性 UI（4s 自清等）用**单次 eval 内联 setTimeout** 检查，别用外部 sleep
   - ⚠️ **`set viewport` 会会话残留**：必须 `close → set viewport → open`，并用 `window.innerWidth` 回验 —— 否则你以为在 1440 测、实际跑在默认 1254，得到**假阴性**（曾据此误判「问题没复现」）
   - ⚠️ **截图命令有 1–2s 延迟**：时长 <2s 的中间态（转场、淡出）抓不到 → 加 `?hold=`／定格参数，或改用下条的**采样曲线**
3.5 **「淡出 / 渐变 / 过渡生硬」类改动的证据 = 透明度曲线，不是截图**：单次 eval 内用 `setTimeout` 连采 `getComputedStyle(root).opacity`，得到 `1.00 → 0.98 → 0.74 → 0.18 → 0` 才算「柔缓」；出现 `1.00 → 0.00` 就是硬切
4. 回归其他路径 + hash 深链（详情/记录/测验各点一次）

## 7. 可访问性（加练项）

- 新交互控件带 `aria-label`；状态提示 `role="status"`、错误 `role="alert"`
- 禁用态：opacity + cursor，不只靠颜色区分
- 键盘可达：输入框可聚焦、按钮可 Tab 到、focus 有可见 outline
- 文字对比度按 §2 硬线**实测数字**，不靠目测

## 8. 文字浮现的节奏（题字类动效，2026-10-01 用户定稿）

用户对仪式题字的要求（2026-10-01 两轮定稿）：「**不要呼吸**」「要有**诏书一般的庄严和神秘感**」。
第一轮我做成**横排一行、逐字向右** → 用户指出「**方向错了**」，并补两条「**没有落下感**」「**停留时间太短**」。
定稿是**竖排两列、右列先**，四条规则：

1. **不要无限循环动画**（浮动 / 呼吸 / 明暗交替）—— 会晃的字是「飘」，不是庄重。
   每字**只落一次**（`animation-iteration-count: 1` + `fill: both`），落定即**静止**
2. **竖排两列、右列先**：逗号前后分列，**DOM 顺序 = 书写顺序**，靠 `flex-direction: row-reverse`
   摆成右列在前（中式书写是右起）。字号按**视口高度**取（用 `vh` 不用 `vw`，否则宽屏会把一列撑爆）；
   字距 / 列距要**疏朗**（0.18em / 0.62em）—— 贴太近会被看成「一列被劈成两半」
3. **匀速逐列**：列内自上而下，间隔恒定（0.19s）；右列落齐**停一拍**（0.55s）左列才起笔
4. **落齐后要静默**：`finish + 1.7s` 之后才让「点击继续」出现。
   提示提前冒出来会把人的手带走，字就白落了 —— 用户报的「停留时间太短」根子在这儿，
   **不在动画时长**（原来提示是 1s 就出现的）

**「落下感」必须分段做**，一锅炖只会变成「一边淡入一边往下飘」：

| 段 | 干什么 | 为什么 |
| --- | --- | --- |
| 0–26% | 字停在上方，只从雾里**显形** | 这一拍是「神秘」 |
| 26–70% | **已经清晰**的字可见地坠下（−0.8em） | 这一拍才是「落」 |

- 缓动要**加速下坠**（`cubic-bezier(.4,.04,.22,1)`）—— 慢起慢停出来的是「飘」
- 位移用 **em**（随字号缩放，屏幕高度一变字距也会变，px 会失配）
- **清晰一定要早于位移到位**：否则字还在雾里就已落地，人会以为它压根没落过（第一轮就这么翻的车）
- 触底后**微沉 0.028em 再回正**，给出落地那一记「顿」

**未出现的字要占位**（`fill: both` 停在起始帧，不可见但保留尺寸）→ 已落定的字位置固定，不会跳。

节奏参数放 JS（`mottoColumns()`，见 `QuizCeremony.jsx`），CSS 只管单字的关键帧 —— 改节奏不用碰样式。
