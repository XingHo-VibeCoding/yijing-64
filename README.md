# 易经六十四卦

《易经》六十四卦的学习与整理项目。

## 项目目标

- 系统整理六十四卦的基本信息：卦名、卦符、卦序
- 逐卦记录卦象、卦辞、爻辞与个人理解
- 形成一份可检索、可长期维护的学习资料

## 目录结构

```
.
├─ README.md            # 项目说明（本文件）
├─ .gitignore           # 忽略规则，保护本地敏感文件不上传
├─ data/
│  └─ 64卦总表.csv      # 六十四卦索引
├─ docs/
│  └─ 01-学习笔记.md     # 逐卦笔记模板
└─ src/                 # 后续放整理脚本
```

## 说明

- 本项目为个人学习整理，卦序采用**通行本（王弼本）**：上经三十卦（1–30）、下经三十四卦（31–64）。
- `.workbuddy/`、`Claw/`、`.env` 等本机私密内容已在 `.gitignore` 中排除，不会上传。
- 提交规范：`Day N｜一句话`，正文两行写「改了什么 / 加了什么」。
