# 易经六十四卦

《易经》六十四卦的学习与整理项目。

## 项目目标

- 系统整理六十四卦的基本信息：卦名、卦符、卦序
- 逐卦记录卦象、卦辞、爻辞与个人理解
- 形成一份可检索、可长期维护的学习资料

## 技术栈

| 层 | 选型 | 备注 |
| --- | --- | --- |
| 前端 | React + Vite | 构建后为纯静态文件 |

| 云端 | CloudBase（云函数 + PostgreSQL + 静态托管） | **只做两件事**：下发卦数据、保存学习进度 |

## 产品边界（来自 Day 3 研究 + Day 4 PRD + Day 5 修订）

1. **不做预测结论** —— 不输出「吉/凶/宜/忌/运势」，不把解读包装成建议
2. **原文与解读必须分层可见** —— 用户要能一眼分清哪句是《周易》、哪句是后人理解
3. **不采集身份信息**（Day 5 新增）—— 学习进度用随机匿名标识关联，不存手机号、邮箱、IP、设备指纹，不做行为埋点

> 由此砍掉了本品类最「好卖」的功能（起卦占卜），换来这个品类的空位：
> **一个认真把「认得出卦象、读得懂原文、记得住卦序」三件事做完的网页工具。**
> 详见 [`docs/PRD.md`](docs/PRD.md) 第 4 节。

> **关于「用户进度」**：打开即用，没有注册和登录。系统在后台生成一个随机匿名标识来关联进度，
> 用户换浏览器或清缓存会丢失进度（这一点在界面上明确告知）。详见 PRD §6 F6 与 §7.3。
