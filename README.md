# 易经六十四卦

《易经》六十四卦的学习与整理项目。

## 项目目标

- 系统整理六十四卦的基本信息：卦名、卦符、卦序
- 逐卦记录卦象、卦辞、爻辞与个人理解
- 形成一份可检索、可长期维护的学习资料

| 层 | 选型 | 备注 |

## 产品边界（来自 Day 3 研究 + PRD v1.2）

1. **起卦保留，但卦只释义、不断事** —— 起卦是核心入口（P0）；解读只讲「这一卦在说什么」，不对未来下断言、不做决策建议、不出现「宜 / 不宜」
2. **吉凶不回避，方向固定** —— 吉卦戒骄躁，凶卦劝慰「运随时变」。这是价值观引导，不是运势判定
3. **原文与解读必须分层可见** —— 用户要能一眼分清哪句是《周易》、哪句是本项目的理解
4. **不采集身份信息** —— 学习进度用匿名标识关联，不存手机号、邮箱、IP、设备指纹，不做行为埋点

> **起卦留着——它是入口；砍掉的是「拿卦替人做决定」的那部分。**
> 换来的空位是：一个能用起卦把你吸引进来、再用卦辞与爻辞把你留在原文里的网页工具。
> 详见 [`docs/PRD.md`](docs/PRD.md) 第 4 节。

> **关于「用户进度」**：打开即用，没有注册和登录。系统在后台生成一个随机匿名标识来关联进度，
> 用户换浏览器或清缓存会丢失进度（这一点在界面上明确告知）。详见 PRD §6 F6 与 §7.3。
