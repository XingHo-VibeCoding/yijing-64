# 易经六十四卦

《易经》六十四卦的学习与整理项目。

## 项目目标

- 系统整理六十四卦的基本信息：卦名、卦符、卦序
- 逐卦记录卦象、卦辞、爻辞与个人理解
- 形成一份可检索、可长期维护的学习资料

## 项目定位（来自 Day 3 需求研究）

> **目标用户：对易经感兴趣、但不是为了算命迷信的人。**
> 六十四卦的「卦名 — 卦象 — 卦序」对不上号，是这类用户最大的门槛。
> 现有工具要么面向占卜、要么面向研究者，唯独缺少「帮我记住」这一层。

**本质：不是算命工具，而是一款让人把六十四卦背下来的学习工具。**

由目标用户推出的两条产品边界：① 不做预测结论；② 原文与解读必须分层可见。
详见 [`docs/research.md`](docs/research.md)。
