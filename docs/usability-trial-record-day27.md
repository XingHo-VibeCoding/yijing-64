## 二、最高优先级卡点与修复

**卡点**：第 3 步。试用任务里「打卡」对应的真实动作是「起一卦→自动存档」，但首屏**没有任何字面提示这一层因果**，且记录页空态是**死胡同**（只有陈述、无出路）。

**为什么选它当最高优先级**：它是试用链路「完成一次核心操作」的正中——**不解决它，后面的刷新/修改/删除全都没有起点**；而其他摩擦（收藏靠猜图标）不影响主流程完成。

**修复**（按模板整理的提示词执行，纯指引、不加功能）：
- 记录页空态新增一句行动指引：「现在就记第一条：回总表点**起 一 卦**，今天起的第一卦会自动出现在这里。」
- 空态新增直达按钮「回总表起一卦」（复用既有 `onBack` 回总表回调）。
- 样式 `.rec-empty-hint` / `.rec-empty-cta`（浅底深墨字、无渐变）。

**修复后复验（本地空态，v1.1）**：
- 空态出现指引文案 + 按钮 ✓
- 点按钮 → 回到总表（hash `#/`）、可见起卦入口 ✓ → **卡点闭环**

## 三、给真人的最小复验任务

**判据**：他看到空态后**没有再问「然后呢」**，而是直接按指引去点了「起一卦」。
