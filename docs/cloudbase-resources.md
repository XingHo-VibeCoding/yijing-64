## 三、导出数据的操作步骤（不含密钥）

本项目数据分三类，导出方式不同：

**① 业务数据（PostgreSQL 五表）**
- 表：`divination_records` / `favorites` / `study_progress` / `study_rounds` / `gilded`
- **只读导出**：用 `managePgDatabase(action="execute", role="anon", sql=…)` 执行 `SELECT`，把结果导出为 CSV/JSON 落本地（`.workbuddy/` 下，**不要提交进仓库**）。
  - 例（导出某人的记录，注意 RLS 只看得到自己的行）：
    `select date, hexagram_id, changing_lines from divination_records order by date desc;`
- ⚠️ 导出含真实用户数据 → 落地文件**必须**在 `.workbuddy/`（已 gitignore），**绝不能**进仓库或外发。
- ⚠️ 本项目**无数据库快照/时间点恢复**，所以「导出」是唯一的离线留存手段——重要变更前先导一份。

**② 代码**
- 远端 GitHub 已是唯一可靠备份；每个发布版本打了 git tag（`v1.0`、`v1.1`），回滚锚点都在。

**③ 静态托管产物**
- 各版本构建产物在 `.workbuddy/release/<版本>/dist`（含 `manifest.json` 记录每文件 sha256），随时可重传回滚。
