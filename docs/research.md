# 需求研究 · 易经六十四卦学习

> 日期：2026-09-18 ｜ 阶段：Day 3 需求研究 ｜ 下一步：Day 4 PRD

## 0. 项目与目标用户

| 项 | 内容 |
| --- | --- |
| 项目 | 易经六十四卦学习 |
| 目标用户 | **对易经感兴趣、但不是为了算命迷信的人** |
| 用户想要的 | 认识六十四卦、读懂卦辞、把「卦名 ↔ 卦象 ↔ 卦序」对上号 |
| 用户不想要的 | 被推销运势、被预测吉凶、被要求相信某套解释 |

**由目标用户直接推出的两条产品边界（贯穿全文）：**

1. **不做预测结论。** 不输出「吉/凶/宜/忌/运势」判断，也不把解读包装成建议。
2. **原文和解读必须分层可见。** 让用户一眼分清「这是《周易》里的话」还是「这是后人的理解」——这是「不算命」这件事在界面上的具体落地方式。

> 补充：六十四卦本身是先秦经典，属于哲学与文献范畴；「用它来预测吉凶」是后世的一种用法。本项目服务的是前者。

### 1.1 爱周易 · 易经（iOS App，个人开发者）

**定位**：离线优先的《周易》研读工具，明确声明「不是占卜工具」。

#### 页面结构
> 依据官方商店的功能描述整理，**未实机验证**，以下为推断结构。

```
首页          每日一卦 / 继续阅读 / 学习进度入口
目录页        按「上下经、八宫、八卦、十翼、名句」多条路径浏览；可分区显隐
卦详情页      卦名（本名/拼音/象名/英文/一句话提示）
              卦辞 → 爻辞 → 彖传 → 象传
              原文 / 白话 / 拼音 / 英译 四层开关
              关系卦导航：互卦 · 错卦 · 综卦 · 之卦
沉浸阅读页    全屏专注，横排/竖排可切，字号 50%–300%
诵读工作台    中英文朗读、多卦连读队列、高亮跟读
测验页        六种模式：卦名 / 卦象 / 卦序 / 卦辞填空 / 爻位 / 八卦基础
              答题即时反馈 + 正确率
学习档案页    阅读历史 · 精通卦象 · 笔记 · 起卦体会 · 错题记录
搜索页        全文检索，范围可选（全部 / 卦名 / 原文 / 白话 / 英文）
起卦页        金钱卦、大衍筮法「文化流程体验」，结果含本卦/之卦/动爻
设置页        英译显示方式、白话/拼音/象传开关、通知、小组件
```

#### 主要数据
- 六十四卦全文：卦辞、爻辞、彖传、象传
- 十翼：系辞上下、说卦、序卦、杂卦
- 八卦基础：象数、方位、自然属性
- 名句精选
- 四种文本层：原文 / 白话 / 拼音 / 英译
- 关系数据：互卦、错卦、综卦、之卦
- 用户数据：阅读历史、笔记、掌握度标记、收藏卦单、错题、连续学习天数

#### 用户能完成的动作
- 按分类浏览、回到上次读到的地方
- 逐卦阅读，随时开关白话/拼音/英译
- 全屏沉浸阅读、切换横竖排版、缩放字号
- 听读（中英朗读、多卦连读、跟读高亮）
- 做六种测验、看正确率、把错题重新练
- 把卦加入收藏、组成自定义卦单、生成卦象分享卡
- 标记「已掌握」，看到学习进度
- 走一遍金钱卦/大衍筮法的文化流程，保存起卦记录并事后编辑体会
- 本地全文检索

#### 优点
- **学习闭环做得最完整**：读 → 练 → 复习 → 进度可视，这是教育产品的正规打法
- 把「关系卦」显性化，帮用户看见卦与卦之间的结构
- **起卦被降级为「文化仪式体验」并在界面内持续免责**，与「不算命」的定位不冲突
- 无账号、无广告、无追踪、无第三方分析 SDK，离线可用

#### 不足
- iOS 独占，Android 和网页用户用不上
- 功能密度高，新用户进来容易不知道从哪开始
- 「十翼 + 六种测验 + 诵读 + 起卦」对只想认全六十四卦的人是信息过载

### 1.2 易经宝典 · 周易六十四卦（iOS App）

**定位**：面向国学爱好者和初学者的图文速查 + 记忆测验工具。

#### 页面结构
> 同样依据商店描述整理，**未实机验证**。

```
卦列表页      六十四卦列表，可简繁切换
卦详情页      卦辞、爻辞、彖传、象传 + 现代译文
图表页        基础八卦 / 先天八卦图 / 后天八卦图 / 八宫六十四卦图 / 卦名次序歌
测验页        八卦测验 + 六十四卦测验（看卦象选卦名、随机出题、即时反馈、显示正确率）
设置页        简体/繁体切换、音效开关
```

#### 主要数据
- 六十四卦的卦辞、爻辞、彖传、象传 + 现代译文
- 八卦方位、阴阳、五行属性
- 八宫六十四卦图、卦名次序歌
- 测验答题次数与正确率

#### 用户能完成的动作
- 浏览/查阅任意一卦的原文与译文
- 看八卦与六十四卦的图表关系
- 做「看卦象选卦名」的测验、看正确率
- 切换简体/繁体

#### 优点
- **「看卦象选卦名」这个交互，直接命中「卦象认不出」这个核心痛点**
- 八宫图和卦名次序歌，针对「卦序记不住」
- 国风视觉 + 楷体阅读，符合这一类用户的审美
- 内容量适中，比爱周易轻，初学者入场压力小

#### 不足
- 内容偏「陈列」而非「教学路径」：给你图表，但不告诉你先学哪个
- App Store 未积累足够评分，**产品是否还在持续维护无法确认**
- 同样 iOS 独占
- 没有搜索、没有原文/白话的分层标注

### 1.3 daooracle.life（网页学习站，中英双语）

**定位**：中英双语的《易经》学习与反思工具，兼顾内容深度和场景解读。

#### 页面结构
> 这一项**已实际抓取页面核实**，结构准确。

```
标题区        卦序 + 卦符 + 卦名 + 拼音 + 英文名（䷎ 谦 · Modesty）
Contents      页内锚点目录，11 个区块可跳转
卦象组成      上卦 / 下卦：卦符 + 卦名 + 自然意象（坤·地 / 艮·山）
卦辞          中文原文 + 英译 + 出处《周易》
              ★ 来源层级标注块：Tier=Classical Text / Registry ID=zhouyi-ctext / Scope / Reference 链接
象辞          中文原文 + 英译
现代释义      白话解读 + ★ 解读边界标注（Tier=Dao Oracle Interpretation，声明非经典原文、非专业建议）
应用场景      事业与决策 / 关系与合作 / 身心与节奏 三段
              ★ 场景化占卜入口：姻缘、事业、财运、健康、搬迁、抉择、婚姻、考试（8 个链接）
爻辞          6 个爻，每爻：爻题（初六/六二…）+ 中英原文 + 小象
变卦关系      6 个爻变的跳转卡（第 N 爻变 → 明夷/升/坤/小过/蹇/艮），带卦符与卦名
关联卦        互卦 / 错卦 / 综卦 / 交卦 / 序对卦，每个带卦符、卦名、英文名、算法说明
实用指导      长文中英对照
场景解读      感情姻缘 / 事业发展 / 财运 / 健康，四段中英双语 + 免责声明
FAQ           3 条常见问答（中英），如「为什么谦卦是唯一六爻皆吉的卦」
```

#### 主要数据
- 每卦：卦序、卦符、卦名、拼音、英文名
- 上下卦：卦符、卦名、自然意象
- 卦辞、象辞、爻辞（6 条）、小象 —— 均有中英双语
- 变卦关系（6 条）、关联卦（互卦/错卦/综卦/交卦/序对卦）
- **来源元数据**：Tier（来源层级）、Registry ID、Scope（适用范围）、Reference（出处链接）
- 场景标签：事业 / 关系 / 身心 / 感情 / 财运 / 健康
- FAQ 问答

#### 用户能完成的动作
- 用页内目录在 11 个区块之间跳转
- 阅读中英对照原文，点击 Reference 跳到 ctext.org 原文出处
- 展开爻辞、点进任一爻变查看新卦
- 点进互卦/错卦/综卦/交卦，观察卦与卦的结构关系
- 看某一卦在事业/感情/财运/健康场景下的解读
- 点场景化占卜入口，进入起卦流程（Start a Reading）
- 读 FAQ

#### 优点
- **「来源层级」标注是全站最值得抄的设计**：明确区分「经典原文」和「后人解读」，还给出 Registry ID 和出处链接。这正好落地了「不算命」所需的信任感
- **关联卦的算法说明写得很清楚**（互卦取二至五爻、错卦阴阳互换、综卦上下颠倒、交卦上下卦互换），不让人猜
- 单页信息密度高但分层清晰，一页就能把一个卦看透
- 中英双语，覆盖面更广
- 有 FAQ，主动回答用户最困惑的问题

#### 不足
- **没有任何记忆/学习功能**：没有测验、没有进度、没有收藏、没有复习。读完就结束了
- 内容偏「解读型」，站内同时提供占卜入口——**「学习」和「占卜」两条线混在一起**，对「不是为了算命」的用户是干扰
- 页面很长（11 个区块），没有「作者认为的重点」
- 未标明六十四卦是否全部覆盖完成

### 1.4 补充参照（不作为主要竞品）

**易经思维（Android App，公司产品）**
功能覆盖最全的一档：卦辞爻辞+白话+现代解读、动态卦象推演（模拟阴阳爻变）、难度分级、每日一卦、卦象日记、思维导图、云同步笔记、起卦工具（硬币/时间/数字，自动生成本卦/互卦/变卦）、AI 问答助理、朗读、社区共修打卡、离线藏经阁。约 35 MB，备案号 京ICP备09030993号-6A。
→ **反面教材：功能越全，初学者决策成本越高。**首次进入要填兴趣问卷、选学习路径，对「我只想先把 64 卦认全」的人是负担。

**ctext.org 中国哲学书电子化计划**
《周易》全文 + 十翼，王弼注本，开放获取、免费，支持全文检索与版本对照。
→ **不是竞品，是基础设施。**它说明一件事：**原文文本本身免费且开放，没有版权壁垒，也就不构成竞争壁垒。**任何人都能在一天内把数据搬走。

## 3. 结论

1. **竞争点不在「能不能起卦」，在「能不能帮我记住」。**
   三个产品里没有一款把「卦象 ↔ 卦名 ↔ 卦序」的记忆做成主路径。爱周易做了测验但埋在第二层，易经宝典只做了测验没做进度，daooracle.life 完全没有记忆功能。**这块是空的。**

2. **「原文 / 白话 / 解读」分层标注，是「不算命」定位在界面上的落地方式。**
   爱周易用开关控制，daooracle.life 用 Tier + Registry ID + 出处链接。后者更彻底、更值得学。

3. **内容不是壁垒，学习闭环才是。**
   ctext.org 已经把最权威的原文免费开放，一天就能搬完。能拉开差距的只有：测验设计、进度可见、反馈即时。

4. **功能越全，初学者越容易跑。**
   爱周易（功能最多）和易经思维（功能最全）都有入场压力；易经宝典（功能最少）反而最容易上手。**做减法是这个项目的机会，不是妥协。**

## 4. 哪个产品改变了我的想法

**是「爱周易 · 易经」。**

**原本的想法**：做一个易经项目，免不了要碰起卦占卜——这是这类产品最抓眼球的卖点，不做就是自废武功。

**改变在哪**：它的做法完全相反。起卦功能**做了，但被降级为「文化仪式体验」**，并在界面里持续声明「不构成占卜、预测、运势判断或任何决策建议」。真正的主线是**学习闭环**：六种测验 + 掌握度标记 + 错题本 + 连续学习天数。

**视角换了**：这个产品的本质不是「算命工具」，而是**一款让人把六十四卦背下来的学习工具**——它的竞品不是各种排盘 App，而是 Anki 这类记忆工具。

**直接后果**：既然本质是记忆工具，25 天的 MVP 就应该先做「认得出卦象」这一个动作的闭环，其余全部延后。这条判断决定了下面第 5、6 节。

## 5. 我能在 25 天内完成的最小版本

**形态：一个纯前端网页应用**（不用登录、不用后端、不用服务器）。选网页的理由：三个竞品里两个被平台绑死，网页谁都能打开，也最容易做出来。

**一句话定义**：**能查、能记、能读**的六十四卦学习页。

| 阶段 | 天 | 做什么 | 完成标志 |
| --- | --- | --- | --- |
| 一 · 能查 | 第 1–7 天 | 六十四卦列表页（序号+卦名+卦符+上下卦）；单卦详情页（卦象图按爻线绘制、卦辞原文、象辞） | 64 卦能点开看，卦象图画得对 |
| 二 · 能读 | 第 8–14 天 | 爻辞（6 条）+ 小象；**原文/白话分层切换**；每段标注来源（原文 or 现代解读） | 一眼能分清哪句是经典、哪句是解读 |
| 三 · 能记 | 第 15–21 天 | **核心交互：看卦象选卦名**（三选一，即时反馈，计分）；连对/连错提示；进度存在浏览器本地 | 能做一轮 20 题并看到分数变化 |
| 四 · 能找 | 第 22–25 天 | 搜索（按卦名/序号）；按上下卦筛选；补一个「上一卦/下一卦」快速翻页 | 输入「谦」能直接跳到第 15 卦 |

**数据来源**：基于已有的 `data/64卦总表.csv` 扩成含卦辞/象辞/爻辞的完整数据文件；原文以 ctext.org 王弼本为准并标注出处。

**验收**：随便挑一卦，能在 3 次点击内看到它的卦象、卦辞和它对应的白话；能做一轮测验并拿到分数。

## 6. 本期不做

| 不做的事 | 为什么不做的理由 |
| --- | --- |
| **起卦 / 占卜 / 运势判断** | 与目标用户直接冲突。研究显示头部产品都把它降级或免责处理，不是必经之路 |
| **输出任何「吉/凶/宜/忌」结论** | 「不算命」是这个项目的立身之本，一旦输出结论就变味了 |
| **账号体系 / 登录** | MVP 阶段零用户，登录只会劝退；学习进度先用浏览器本地存储 |
| **云端同步 / 社区 / 打卡排行** | 需要后端与运维，成本远超本期收益 |
| **AI 解卦问答** | 没有靠谱的评判标准，容易输出似是而非的内容，直接损害信任 |
| **十翼全文（系辞/说卦/序卦/杂卦）** | 范围太大；本期只做六十四卦本体 |
| **变卦与关联卦推演（互卦/错卦/综卦/交卦）** | 属进阶内容。用户连本卦都还没认全时没有价值 |
| **中英文对照 / 朗读 / 音效 / 卦象分享卡** | 体验增强项，不是核心闭环，优先级最低 |
| **简体繁体切换** | 有真实需求但不是早期瓶颈 |
| **App 上架（iOS / Android）** | 先做网页验证需求；审核与维护成本不属于 MVP |
| **图表页（先天/后天八卦图、八宫图、卦名次序歌）** | 易经宝典已经做得很好，重复造轮子不如把力气放在记忆闭环上 |
